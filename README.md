ME-Tech | Soluciones Tecnológicas

Soporte técnico profesional para Hardware, Software. Esta es la plataforma web oficial de ME-Tech, diseñada para ofrecer asistencia técnica rápida y eficiente en Paraguay.



Características del Proyecto
- **Diseño Moderno y Limpio:** Enfocado en la conversión y la experiencia del usuario (UX).
- **100% Responsivo:** Optimizado para dispositivos móviles, tablets y escritorio.
- **Recursos Locales:** Fuentes (Poppins) e Iconos (Font Awesome) servidos localmente para mayor velocidad y privacidad.
- **Carrusel Interactivo:** Sistema de diapositivas con Bootstrap 5 para destacar servicios principales.
- **Modales de Contacto:** Formulario de solicitud de asistencia técnica integrado.



## 🛠️ Tecnologías Utilizadas
Este proyecto ha sido desarrollado utilizando:
- **HTML5 & CSS3** (Custom Properties / Variables).
- **Bootstrap 5** (Framework de diseño).
- **PHP 8** (Lógica de servidor y modularización de componentes).
- **JavaScript** (Interacciones dinámicas).
- **Font Awesome 6** (Iconografía local).
- **Google Fonts** (Tipografía Poppins local).
